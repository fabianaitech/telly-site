# telly-site

The small website for Telly, an IPTV player for Apple TV, iPhone, iPad and Mac.
It hosts Telly's support and privacy pages (linked from the App Store listing),
served with GitHub Pages at https://fabianaitech.github.io/telly-site/.

- `index.html`: home page
- `support.html`: support and common questions
- `privacy.html`: privacy policy
